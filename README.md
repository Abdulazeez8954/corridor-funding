# CORRIDOR FUNDING

Professional private lending and financial services platform.

## ABSOLUTE FOLDER RULE
This project follows a strict **FLAT** structure. 
- NO subfolders (e.g., no `/css`, no `/js`, no `/assets`).
- Every file must be in the root directory.

## Tech Stack
- HTML5 / CSS3 / Vanilla JavaScript
- Firebase 12.18.0 (Auth, Firestore)
- Vercel Hosting
